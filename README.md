# Deep Sea Hide & Seek 🐳🧽🧸

A cute hide-and-seek game in the deep sea's midnight zone, starring Mr. Whale, Mr. Sponge and Blankie Bear.

- Pick a character, then play rock-paper-scissors. The loser is the seeker.
- **Hiding:** use the arrow keys to hide behind coral, rocks, kelp, shells… Move slowly so the seeker can't hear you!
- **Seeking:** find everyone before time runs out. Watch for bubbles, giggles and sneaky shadows.
- Space / Enter: say hi (makes noise!). `M`: mute.
- Look out for easter eggs: a treasure chest, a rubber duck, a yellow submarine, and Mama Whale.

Plain HTML/JS, no build step. Run locally with `python3 -m http.server` and open http://localhost:8000.
Every push to `main` deploys to GitHub Pages (`.github/workflows/deploy.yml`).
